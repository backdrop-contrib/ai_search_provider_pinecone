# AI Search Provider Pinecone

Store AI Search embeddings in an existing Pinecone index and retrieve similar content for Backdrop search. Each Search API index uses its own namespace.

## Installation

Enable AI Search, Key, and this module. Choose **Pinecone** when creating a Search API server. [Backdrop module installation guide](https://backdropcms.org/user-guide/modules)

[Setup and troubleshooting](https://github.com/backdrop-contrib/ai_search_provider_pinecone/wiki)
